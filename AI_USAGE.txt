2. NHỮNG GÌ AI ĐÃ HỖ TRỢ
--------------------------
  a) Thiết kế kiến trúc ETL:
     - Tư vấn cấu trúc Control Flow gồm 9 task theo đúng thứ tự
       phụ thuộc (Precedence Constraint):
       Clear DDS → Load DimDate → Load DimCustomer → Load DimProduct
       → Load Fact ERP → Stage POS & Online → Load Fact POS
       → Load Fact Online → Load Rejected and Duplicates

  b) Sinh tự động file Package.dtsx:
     - Viết C# script sử dụng SSIS Managed API (Microsoft.SqlServer.Dts)
       để tạo file Package.dtsx theo đúng chuẩn SSIS Data Flow Task:
         OLE DB Source
           → Derived Column  (tính DateKey, SourceSystem, GrossAmount, NetAmount)
           → Lookup DimCustomer  (tra cứu CustomerKey)
           → Lookup DimProduct   (tra cứu ProductKey)
           → OLE DB Destination  (nạp vào FactSales)
     - Áp dụng cho cả 3 task: Load Fact ERP, Load Fact POS, Load Fact Online

  c) Viết SQL logic ETL:
     - SQL BULK INSERT cho POS.csv (xử lý CRLF, encoding)
     - SQL INSERT inline cho dữ liệu Online
     - SQL lọc dữ liệu hợp lệ (WHERE clause phức tạp)
     - SQL INSERT vào ETL_RejectedRows với CASE phân loại lý do từ chối
     - SQL phát hiện Duplicate TransactionNo theo thứ tự ưu tiên
       ERP > POS > ONLINE

  d) Debug và sửa lỗi:
     - Lỗi truncation warning: varchar(50) → varchar(20)
     - Lỗi code page mismatch: 1252 vs 1258 (Vietnamese collation)
     - Lỗi Derived Column: thiếu ErrorRowDisposition / TruncationRowDisposition
     - Lỗi Lookup: duplicate JoinToReferenceColumn property
     - Lỗi "Row yielded no match during lookup" (C999 không có trong DimCustomer)
       → Fix: đặt NoMatchBehavior = 1 (Redirect thay vì Fail)

  e) Viết script kiểm tra kết quả:
     - SQL verify: đếm row count, tổng hợp doanh thu, phân loại rejected rows
     - Script show mẫu dữ liệu kết hợp star schema (Fact JOIN Dim)
